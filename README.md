## Acesso

Sistema on-line: **https://ramaoh.github.io/erp-fabrica-x/**

Funciona no navegador, sem instalação e sem internet após aberto. Os dados ficam salvos no navegador de quem usa (exporte o backup em *Configurações*).

## Módulos

| Área organizacional | Módulo |
|---|---|
| Administração de materiais | Movimentações, inventário e divergências |
| Classificação de materiais | Curva ABC, classificação XYZ e matriz ABC-XYZ |
| Planejamento de estoques | Ponto de pedido e estoque de segurança |
| Qualidade / BPF | Lotes, FEFO e rastreabilidade |
| PCP | Fórmulas (dietas) e ordens de produção |
| Suprimentos | Pedidos de compra, recebimento e fornecedores |
| Organização e melhoria | Auditoria 5S e plano de ação 5W2H |
| Custos | Valor do estoque, perdas, giro e custo por tonelada |

## Arquivos

- `index.html` – o ERP (arquivo único).
- `planilha/Ficha_Controle_Estoque_Fabrica_X.xlsx` – ficha de controle diário para coleta em campo (controle diário, instruções e modelo FEFO/ponto de pedido).

## Aviso

Os dados que acompanham o sistema são **ilustrativos (fictícios)** e servem apenas para demonstração. A unidade estudada é identificada como “Fábrica X”; dados reais só devem ser usados com autorização da gestão da propriedade.
